# NS Traders Website

A responsive construction materials website for NS Traders, Puducherry.

## 🚀 Features

- Responsive design (mobile, tablet, desktop)
- Product catalog with WhatsApp integration
- Service showcase (Transport & Earth Movers)
- Contact form with WhatsApp messaging
- Admin panel for poster management
- Image upload and preview
- Local storage for poster data

## 🛠️ Setup

1. Clone the repository
2. Open `index.html` in browser
3. For admin access, click "Admin" button (password: `admin123`)

## 📱 Pages

- **Home** - Hero section with video background
- **Products** - M Sand, P Sand, River Sand, Jalli, etc.
- **Services** - Transport & Earth Movers rental
- **Gallery** - Project images
- **Contact** - Form with WhatsApp integration
- **Admin** - Poster management (password protected)

## 🔧 Technologies

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript
- LocalStorage (for poster data)
- WhatsApp Business API
